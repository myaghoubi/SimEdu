# ساختمان داده – آموزش تصویری (PWA)

محیط آموزشی برای درس ساختمان داده: کد **شبه‌پایتون** را خط‌به‌خط اجرا می‌کند و پس از هر گام، حافظه را به‌صورت **گرافیکی و متحرک** نشان می‌دهد.
بدون وابستگی و بدون مرحلهٔ build؛ فقط HTML + CSS + JavaScript. به‌صورت PWA نصب‌شدنی است و آفلاین کار می‌کند.

## امکانات
- مفسر شبه‌پایتون (کلاس، وراثت، بازگشت، `try/except`، comprehension، f-string، …) که با generator اجرا می‌شود؛ هر دستور یک «گام» است.
- گام بعد / گام قبل / عبور (Over) / خروج (Out) / اجرای خودکار / ادامه تا نقطهٔ توقف / نوار پیمایش گام‌ها.
- نمایش خودکار: آرایه (و نمای میله‌ای)، آرایهٔ دوبعدی، لیست پیوندی یک‌طرفه و دوطرفه، درخت دودویی، درخت عمومی، گراف (لیست مجاورت، وزن‌دار، ماتریس مجاورت، اشیای رأس)، دیکشنری، مجموعه.
- اشاره‌گرها (`root`، `cur`، `i`، `j`، …) به‌صورت برچسب رنگی روی گره‌ها؛ یال تازه و مقدار تغییرکرده چشمک می‌زنند.
- ویرایش زندهٔ کد: با هر تغییر، اجرا از ابتدا آماده می‌شود و اثر تغییر در اجرای گام‌به‌گام دیده می‌شود. خطای نحوی و زمان اجرا روی خط مربوط نشان داده می‌شود.
- پشتهٔ فراخوانی، متغیرها، خروجی `print`، تابع `note("...")` برای توضیح در حین اجرا.
- مثال‌ها: **درج AVL، حذف AVL، چهار حالت چرخش AVL**، BST، پیمایش درخت، درخت عمومی، لیست پیوندی یک/دوطرفه، آرایه، مرتب‌سازی حبابی، جستجوی دودویی، پشته/صف، BFS، DFS، دایکسترا، ماتریس مجاورت.

## اجرای محلی
```bash
python3 -m http.server 8080      # یا هر وب‌سرور ایستای دیگر
# سپس http://localhost:8080 را باز کنید
npm test                          # آزمون‌ها (Node 18+)
```
(Service Worker فقط روی `https` یا `localhost` فعال می‌شود.)

## گذاشتن در GitHub و انتشار (GitHub Pages)
```bash
cd dsviz
git init -b main
git add .
git commit -m "ساختمان داده – آموزش تصویری"
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```
سپس در GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
با هر push روی `main` ابتدا آزمون‌ها اجرا و بعد سایت منتشر می‌شود (`.github/workflows/pages.yml`).
آدرس: `https://<USER>.github.io/<REPO>/` — همهٔ مسیرها نسبی‌اند، پس در زیرپوشه هم درست کار می‌کند. در Chrome/Edge دکمهٔ «نصب برنامه» ظاهر می‌شود.

> با هر تغییر در فایل‌های برنامه، مقدار `VERSION` را در `sw.js` عوض کنید تا کش قدیمی تازه شود.

## ساختار
| فایل | نقش |
|---|---|
| `js/interp.js` | تحلیلگر لغوی/نحوی و مفسر گام‌به‌گام |
| `js/scene.js` | تشخیص ساختمان داده‌ها از حافظه و ساخت هندسهٔ نمایش (بدون DOM، قابل آزمون) |
| `js/render.js` | رسم SVG متحرک (گره، یال، برچسب اشاره‌گر) |
| `js/examples.js` | مثال‌های آموزشی |
| `js/app.js` | ویرایشگر، کنترل اجرا، پنل‌ها، PWA |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |

## قرارداد نام‌گذاری برای تشخیص ساختار
`left/right` → درخت دودویی · `children` → درخت عمومی · `next` → لیست یک‌طرفه · `next+prev` → دوطرفه · `neighbors` یا دیکشنری مجاورت → گراف. ویژگی‌های دیگر مثل `height` زیر گره نوشته می‌شوند؛ `color='red'/'black'` گره قرمز-سیاه رسم می‌کند.

## محدودیت‌ها
اعداد صحیح و اعشاری در نمایش فرقی ندارند (`3.0` ← `3`)؛ `yield`، `with`، `*args` و ماژول‌های بیرونی (جز `math`) پشتیبانی نمی‌شوند؛ عمق بازگشت ۲۰۰.
